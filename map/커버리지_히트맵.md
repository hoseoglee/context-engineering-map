## 맵에서 제외한 에이전트 내부 도구

> 에이전트 하나 안의 SDK·런타임·대화 기억·창 압축·트레이싱. 기업 규모 컨텍스트 플랫폼이 아니라서 제외.

- **Amazon Web Services**: AgentCore Runtime + Harness, AgentCore Memory, AgentCore Observability + Evaluations (Recommendations, A/B), AWS MCP Server + Agent Toolkit for AWS
- **Databricks**: Genie Code (+ ZeroOps), Agent Bricks (Knowledge Assistant, Supervisor Agent, Sandbox), Agent Memory Service (Lakebase), MLflow 3 GenAI (Tracing, Evaluation, Production monitoring)
- **Google Cloud**: Gemini Enterprise Agent Platform (Agent Runtime·ADK·Studio·Evaluation·Observability), Memory Bank + Sessions, Agent2Agent (A2A) 프로토콜
- **Microsoft**: Foundry Agent Service (hosted agents, Memory, Toolboxes, evals, guardrails), Microsoft Agent Framework (successor to Semantic Kernel / AutoGen), GraphRAG / LazyGraphRAG (open source)
- **Anthropic**: Agent Skills, Context editing + Memory tool (API), Server-side compaction, Claude Managed Agents + Memory
- **OpenAI**: Agents SDK
- **Glean**: Headless agent building
- **Cohere**: Rerank 4
- **LangChain**: LangChain 1.x (middleware, FastMCP), LangGraph, Deep Agents / Managed Deep Agents, LangSmith
- **LlamaIndex**: LlamaParse (formerly LlamaCloud), LlamaExtract (Extract v2.5), LlamaCloud Index, LlamaAgents / Workflows, LlamaParse MCP server
- **Mem0**: Mem0 Platform (v3 algorithm, built-in graph memory), Memory Decay, Mem0 OSS / OpenMemory MCP, Integrations (n8n, Zapier, Strands, coding-agent plugins)
- **Zep**: Graphiti, Zep Agent Skills, Agent memory (user memory)
- **Letta**: Letta Code (+SDK), Context Repositories (MemFS), Client-side reflection subagents (ex sleep-time), Letta API (server)
- **Pinecone**: Pinecone Assistant (+MCP server), Pinecone MCP server, Full-text search + Documents API, Expanded RBAC / SAML-SCIM
- **Elastic**: Agent Builder, Elastic Workflows, Agent trace feedback (OTel)
- **Writer**: Agent Memory
- **Contextual AI**: Agent Composer, Datastores (+Global Datastores), Grounded generation / attributions, Reranker / Parser
- **Alation**: Agent Studio (SDK + Agent Builder)
- **Neo4j**: GraphRAG retrievers + Gemini Enterprise A2A
- **Palantir**: Pro-code agents (Agent templates) + OSDK, Palantir MCP (PMCP), AIP Evolve
- **Snowflake**: Cortex Agents (evaluations, Agent Sharing), Snowflake CoCo (formerly Cortex Code), AI Observability (TruLens)
