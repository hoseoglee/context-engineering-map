# 솔루션 포지셔닝 조사 가이드 (조사자 공통 기준)

기준 맵: `docs/기술맵_설계안.md` 의 **스택 맵**(7개 층 + 기둥 2개)과 **2축 지도**.

## 1. 층 정의 (각 제품이 어느 층을 담당하나)
| 코드 | 층 | 판정 기준 (이 기능이 있으면 해당) |
|---|---|---|
| L1 | 연결·원천 | 데이터 소스 커넥터, MCP/A2A 서버·클라이언트, 벡터·문서 저장소, 인덱싱 |
| L2 | 의미(지표) | 지표·차원·비즈니스 용어 정의(semantic layer/model/view, metric view), 비즈니스 글로서리 |
| L3 | 관계·정체성 | 온톨로지, 지식그래프, 엔티티·관계 모델, ID 매핑/엔티티 해석, GraphRAG |
| L4 | 절차·역할 | 업무 절차/플레이북/지침, 역할별 지시, 워크플로우·승인 체인 정의, 스킬 |
| L5 | 기억·이력 | 에이전트 장기 기억, 대화·이벤트·결정 이력, 계보(lineage)·출처(provenance) |
| L6 | 런타임 창 관리 | 질의별 컨텍스트 선별·랭킹·조립, 토큰 예산, 압축/요약, 라우팅, 멀티에이전트 오케스트레이션 |
| L7 | 실행·검증 | 도구/액션 실행(쓰기), 결정론 함수·계산, 출력 검증·가드레일·근거 확인 |
| GOV | 거버넌스·권한 기둥 | 접근 제어, 에이전트 권한, 사람 승인, 정책 집행, 감사 로그 |
| OBS | 관측·평가 기둥 | 트레이싱, 평가(evals), 품질 모니터링, 신선도 감시 |

표시: `●` 네이티브 핵심 기능 / `◐` 부분 지원·파트너 의존·프리뷰 / 비워 두면 없음.

## 2. 2축 지도 점수 (제품 단위, -2 ~ +2 정수)
- **x (컨텍스트 성격)**: -2 지표·분석(숫자 질문에 답함) … +2 객체·행동(업무 실행·쓰기)
- **y (컨텍스트 생산 방식)**: -2 사람이 미리 큐레이션 … +2 에이전트가 런타임에 스스로 찾고 축적
- 근거 한 줄 필수.

## 3. 성숙도 (FAOS L0~L5) — 제품이 지원하는 최고 단계
L1 컨텍스트 주입 / L2 도구·스킬 발견 제약 / L3 실행 중 승인 게이트 / L4 출력 검증 / L5 폐루프(경험으로 컨텍스트 자동 진화)

## 5. 규칙
- **공식 문서·공식 블로그·릴리스 노트를 1순위 근거로.** 2차 해설만 있으면 `kind: secondary` 표시. 근거가 없으면 칸을 비운다(추정으로 채우지 않는다).
- 컨텍스트 엔지니어링과 관련 있는 제품만 (일반 DB·BI 기능 나열 금지). 회사당 핵심 제품 4~12개.
- 오늘은 2026-11-11. 2025~2026 최신 상태 기준, 제품명 변경·통합 이력 확인.
- 본문은 자기 말로. 공식 문서 문장을 길게 베끼지 않는다(25단어 미만 인용만).
