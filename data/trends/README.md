# Google Trends 원본 데이터

- 수집: `tools/fetch_trends.py` (pytrends, 월별, 웹 검색, 2006-01 ~ 수집일)
- `raw_<지역>_<패널>_<요청>_<clean|full>.csv`: 요청별 원본(요청마다 0~100). clean = 이상 구간 직전까지, full = 수집일까지
- `wiki_en_pageviews.csv`: 보정에 쓴 영문 위키백과 월별 조회수(Wikimedia API, 사람 조회만)
- 합친 값: `map/trends.json` — `series` = 보정값, `raw` = 보정 전, `method` = 용어별 보정 방법
- 다시 계산만: `python3 tools/fetch_trends.py --no-fetch`

## ⚠️ 집계 이상 구간 — 전 세계 2025-06 ~ 2026-09, 한국 2025-11 ~ 2026-09 (보정해서 표시)

수집 결과 거의 모든 대상 용어가 2025-08부터 부풀어 2026-02~06에 최고치를 찍고, 2026-10에 이전 수준으로 돌아왔다.
**주제와 무관한 대조 검색어**로 확인한 결과 (2026-11-11, 전 세계, 한 요청 안의 상대값):

|---|---|---|---|---|---|

- 영어 개발자·기술 용어(python tutorial, unit testing, data warehouse)는 같은 기간에 함께 2~8배 뛰었다가 2026-10에 원복.
- 일반 사무·운영 용어(excel formula, linux command)와 일상어(weather, recipe)는 이 기간에 이런 급등이 없다.
- 따라서 이 구간의 상승은 실제 관심 변화가 아니라 **집계 쪽 이상**으로 판단한다. 원인은 확인하지 못했다(자동화된 검색 유입이 섞였다가 걸러졌을 가능성).
- 주별 데이터로 다시 보면 전 세계는 **2025-06** 부터 부풀기 시작했다(python tutorial 5월 4.5 → 6월 7.2, 위키 Python 조회수는 그대로). 한국은 2025-10 까지 정상이고 **2025-11** 부터다. 그래서 지역마다 구간을 따로 둔다.
- 유튜브 검색(gprop=youtube)에서는 data warehouse 가 이 기간에 평평했다 → 웹 검색 집계에 한정된 이상이다.

### 보정 방법 (2026-11-11)

**위키백과 조회수에는 이 이상이 없다.** 같은 기간 영문 위키 조회수(월, 사람 조회):

| 문서 | 2025-05 | 2025-08 | 2026-02 | 2026-06 | 2026-10 |
|---|---|---|---|---|---|
| Python (programming language) | 109,592 | 116,775 | 119,920 | 114,731 | 169,217 |
| Unit testing | 8,316 | 8,887 | 7,458 | 6,250 | 6,539 |
| Data warehouse | 9,319 | 9,569 | 8,381 | 7,701 | 6,230 |

그래서 위키 조회수를 "이상 구간의 모양"으로 쓴다.

1. **위키 문서가 있는 용어**: 구간 직전 3개월의 `Trends 값 ÷ 위키 조회수` 비율과 직후 비율(Trends는 직후 2개월 평균 ÷ 위키 직후 1개월)을 구해 구간 안에서 로그 선형으로 잇고, 그 달 위키 조회수에 곱한다. 양 끝이 Trends 실측에 맞춰지므로 이음매가 없다.
   - 직전 3개월에 위키 문서가 자리 잡지 않은 용어(예: 전 세계 MCP — 2025-04 문서 신설)는 2번으로 보낸다.
   - 직후 Trends 값이 원 요청에서 정수 3 미만이면(이상 구간 최고점에 맞춰 정규화돼 해상도가 없음) 직후 비율을 믿지 않고 직전 비율을 유지한다.
2. **위키 문서가 없거나 못 쓰는 용어**(GraphRAG, context engineering, AI agent, data catalog, data fabric 등): 같은 차트에서 1번으로 보정한 용어들의 월별 부풀림 배율(원본÷보정) **중앙값**으로 원본을 나눈다. 이 용어 고유의 부풀림과 다를 수 있으므로, 구간 끝에서 실측과 어긋난 만큼을 구간에 걸쳐 선형으로 분배해 이음매를 맞춘다.
3. 한국은 한국어 위키 조회수가 월 수십~수백 건이라 잡음이 커서 **영문 위키**를 썼다. 따라서 이 구간의 한국 값은 "전 세계 위키 독자 흐름 + 한국 Trends 양 끝"으로 만든 추정이며, 한국만의 변화는 담지 못한다.

**한계**: 보정값은 추정이다(맵에서 점선). 위키 독자와 검색 사용자는 다른 집단이고, AI 요약 탓에 위키 조회수 자체가 서서히 줄고 있다(양 끝 비율로 일부 흡수). 중앙값 보정 용어는 오차가 더 크다. 맵에서 "이상 구간 빼기"·"원본 그대로"로 바꿔 볼 수 있다.
