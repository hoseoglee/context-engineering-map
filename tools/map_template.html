회사 전체의 데이터·의미·지식·권한을 여러 AI와 사람에게 공급·통제하는 기업용 솔루션을 7개 층과 2개 기둥에 배치했다. 에이전트 하나 안의 도구(SDK·대화 기억·창 압축)는 제외. 솔루션 이름을 누르면 근거가 나온다. · GitHub

↕ 기둥 — 아래 두 영역은 특정 층이 아니라 위 모든 층에 걸쳐 작동한다.

X축: 숫자·분석에 답하는가(왼쪽) ↔ 업무를 실행하는가(오른쪽). Y축: 사람이 미리 정의한 컨텍스트(아래) ↔ AI가 사용 이력에서 자동으로 만들고 넓히는 컨텍스트(위). 큰 점 = 회사(솔루션 평균), 회사 이름 아래 = 대표 솔루션.

칸 = 그 층을 핵심 기능으로 맡는 솔루션(여러 개일수록 진함). ◐ = 부분·프리뷰·파트너만, 빈칸 = 근거 없음. 솔루션을 누르면 근거, 회사를 누르면 보정 내역이 나온다.
